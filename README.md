# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a Bash-based calculator that calculates simple interest based on the user's input.

The calculator takes the following inputs:

* Principal amount
* Rate of interest
* Time period

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Example

For a principal amount of 1000, a rate of interest of 5%, and a time period of 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100

## Purpose

This project demonstrates a simple calculator using Bash scripting and GitHub.
